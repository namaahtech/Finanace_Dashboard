## **NLP ANALYSIS PROMPTS FOR GEMMA4**

Use these prompts when sending resume + job cluster to your local Gemma4 model:

```
PROMPT_TEMPLATE_1: SKILL MATCHING
---
Given the following job cluster:
{job_cluster_json}

And this resume:
{resume_text_from_ocr}

Perform detailed skill matching:
1. List mandatory technical skills found in resume (with relevance score 0-100)
2. Identify missing mandatory skills
3. List bonus skills present
4. Assess domain knowledge depth (0-100)
5. Overall technical match percentage

Response format:
{
  "technical_match": 0-100,
  "found_skills": ["skill": "score"],
  "missing_critical": ["skill"],
  "bonus_skills": ["skill"],
  "domain_depth": 0-100,
  "explanation": "brief reasoning"
}
---

PROMPT_TEMPLATE_2: EXPERIENCE ASSESSMENT
---
Job cluster required experience: {exp_required}
Resume shows: {exp_from_resume}

Assess:
1. Years of relevant experience
2. Depth of hands-on experience vs theory
3. Project complexity alignment
4. Seniority level match
5. Growth trajectory evidence

Response format:
{
  "experience_match": 0-100,
  "years_relevant": number,
  "complexity_alignment": 0-100,
  "seniority_fit": "Junior|Mid|Senior|Overqualified",
  "growth_indicators": ["indicator1", "indicator2"]
}
---

PROMPT_TEMPLATE_3: OVERALL COMPATIBILITY
---
Resume:
{resume_full_text}

Job Cluster:
{job_cluster_name}

Provide comprehensive analysis:
1. Overall fit percentage (0-100)
2. Top 3 matching areas
3. Top 3 gaps
4. Recommendation: Suitable|Partially Suitable|Not Suitable
5. Suggestions for candidate to improve fit

Response format JSON with all above fields + detailed explanation
---
```
